# Keylogger با Java و JNativeHook

**Keylogger ساده و پیشرفته نوشته‌شده با زبان Java با استفاده از کتابخانه [JNativeHook](https://github.com/kwhat/jnativehook)**  
این برنامه کلیدهای فشرده‌شده کاربر را ذخیره کرده و می‌تواند به‌صورت مخفی اجرا شود.

---

## 📌 ویژگی‌ها

- استفاده از کتابخانه Native برای ثبت رویدادهای کیبورد
- اجرا به‌صورت مخفی در پس‌زمینه (بدون نمایش کنسول)
- ذخیره‌سازی لاگ کلیدها در فایل متنی محلی
- قابلیت اجرا به‌صورت خودکار از طریق اسکریپت Shell

---

## ⚙️ پیش‌نیازها

- Java JDK 17 یا بالاتر  
- Maven برای مدیریت وابستگی‌ها  
- سیستم‌عامل Linux یا Windows  
- کتابخانه `jnativehook` (به‌صورت local اضافه شده در پروژه)

---

## 🛠️ نحوه ساخت

1. کلون کردن پروژه:
   ```bash
   git clone https://github.com/yourusername/Keylogger.git
   cd Keylogger
````

2. ساخت فایل اجرایی JAR:

   ```bash
   mvn clean package
   ```

3. اجرای برنامه:

   ```bash
   java -jar target/Keylogger-1.0-SNAPSHOT.jar
   ```

---

## 🐚 اجرای مخفی در Linux

از اسکریپت زیر استفاده کنید تا برنامه بدون کنسول اجرا شود:

```bash
#!/bin/bash
JAR_PATH="/home/toor/Downloads/stroe/Keylogger/target/Keylogger-1.0-SNAPSHOT.jar"
chmod 700 "$JAR_PATH"
nohup java -jar "$JAR_PATH" >/dev/null 2>&1 &
```

---

## 🔐 امنیت و دسترسی

* فایل JAR به‌صورت پیش‌فرض با دسترسی فقط برای کاربر اجراکننده تنظیم می‌شود.
* برنامه هیچ ارتباطی به اینترنت ندارد مگر اینکه خودتان توسعه دهید.
